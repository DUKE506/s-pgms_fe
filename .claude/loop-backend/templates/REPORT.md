붙인다. 화면에서 안 쓰는 응답 필드는 "미사용(이유)"로 명시 — 조용히 빼지 않는다.

---

## #NN [역할] 화면명 — {연동 완료 / 부분완료(△) / 검증 완료}

첫 문장: **무엇을 연동했는지 한글로 한 줄**. (예: "피전이 게스트 계정을 발급→조회권
수정→삭제하는 `/guests` 화면. mock 6종을 실 `User/Police/W/` 엔드포인트로 전환.")
검증전용이면: "코드 신규 없음 — {재사용 구조 설명}. 이번 iteration = {무엇을 검증}."

## 연동 내용

| 함수 | API | 화면 위치 | 설명 |
|---|---|---|---|
| `함수명` | `GET/POST ...` | 어느 표/버튼/다이얼로그 | 응답→화면 필드 매핑 요지, mock과 다른 점 |

제거/대체한 것: `구 함수` → 사유. 테스트 더블: `handlers/*` 무엇을 어떻게.
