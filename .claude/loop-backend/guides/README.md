- **`PROBE.md`** — 프로브 실무 (LOOP 3단계): `_probe-NN.sh` 작성·실행, `settings.local.json`
  allow 규칙, 부작용 호출 처리, 함정, 응답 샘플 저장.
- **`SECTION_BOUNDARY.md`** — 섹션 종료 절차 (LOOP 10단계): `findings.md` 누적분 → 요청서
  `.md` + `.xlsx` 생성 → `requests/` 저장·전달. 섹션 분할 규칙.
