# backend-integration/

**"무엇을 연동하는가"의 기록** — 연동 대상, 발견 사항, 실측 근거, 백엔드로 나간 산출물.

| 파일/폴더 | 무엇 |
|---|---|
| `matrix.md` | 연동 대상 카탈로그 — 역할×화면×API + 화면 간 의존성(진행 순서 근거) |
| `findings.md` | 발견 레지스터 — 요청 / 질문 / 블로커 / 제외 + 상태 |
| `responses/` | 실측 응답 원본 (1 엔드포인트 = 1 파일) |
| `requests/` | 섹션 종료 시 백엔드로 전달한 요청·논의 (`.md` + `.xlsx`) |

**"어떻게 일하는가"**(절차·게이트·상태·템플릿)는 `.claude/loop-backend/`.
스웨거 원본은 `../api-swagger.json`, 실제 DB 스키마는 `../db-dump/`.
