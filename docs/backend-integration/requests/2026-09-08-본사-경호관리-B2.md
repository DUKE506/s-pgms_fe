# 백엔드 요청·논의 — 섹션 B (본사 경호관리)

> **작성일**: 2026-09-08 · **대상 섹션**: 그룹 B (본사 경호관리) B-1(#6~9)·B-2(#10~12) 통합
> **상태**: 백엔드/운영본부 전달 예정. 근거는 `docs/backend-integration/findings.md` 각 번호.

경호건 생명주기 순서. 회신·연동 완료분(배치기간·배치요구서 원본조회·경찰 `GetDeployDetail`
조치/근무시간)은 제외했다.

**참고: 전부 "고쳐달라"가 아니라, 운영본부와 워크플로우 자체를 정해야 하는 항목이 섞여 있다.**

유형: 결정(운영팀 문의) / 논의(프론트 방향) / 요청(백엔드 구현)

## 재검토 — 요청에서 제외

- **경호계획 조치 5섹션 ↔ `summary1~5`**: 섹션당 기간이 1개라 `summaryNDate`(단일)와 일치 —
  문제 없음. `summaryN`이 다중선택 항목을 `", "` join으로 받는 것만 소프트한 부분인데 항목
  라벨에 쉼표가 없어 현재 정상 동작.
- **경호목록 지역청 필터**: `GetGuardCaseList.parentGroupName`이 이미 옴 → 프론트 미연동일
  뿐. 섹션 B 마무리 후 프론트 후속작업.
