# requests/ — 백엔드 일괄 요청서

한 섹션의 연동 작업 중 `../findings.md`에 쌓인 요청/질문/블로커 항목을 **섹션이 끝날 때
한 번에 묶어** 백엔드에 전달하는 문서(`TASK.md` "개발은 화면 단위 / 백엔드 요청은 섹션 단위").

## 파일 규칙

- 파일 1개 = 섹션 1개. 이름: `{YYYY-MM-DD}-{섹션명}.md` (+ 동반 `.xlsx`)
  예: `2026-09-08-게스트-D.md`
- 구조: 제목 / 대상 섹션·상태 / 연동 완료분(요청 제외) / `화면·기능·지금 상태·필요한 것·유형·근거` 표.
- `findings.md`의 항목 번호를 근거로 병기하되, 문서 자체는 백엔드에 그대로 전달 가능한
  형태로(프론트 내부 맥락 최소화) 작성.

## 작성 시점

`../../../.claude/loop-backend/LOOP_INSTRUCTIONS.md` 10단계 → 상세는
`../../../.claude/loop-backend/guides/SECTION_BOUNDARY.md`(`.md` + `.xlsx` 만드는 법 포함).
전달 후 응답은 기다리지 않고 다음 섹션으로. 완료 통보가 오면 회신반영 iteration으로
코드에 반영하고 `findings.md` 상태를 🟡→🟢으로 갱신한다.
