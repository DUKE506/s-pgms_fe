# 개발 로드맵

핵심 워크플로우를 얇게 한 바퀴 먼저 돌린 뒤 목록 → 이력/부가기능 → 대시보드 순으로 확장합니다.
진행하면서 체크박스를 갱신합니다.

각 항목은 담당 계정(`[경찰서]`/`[본사]`/`[본청/지역청]` 등)을 태그로 표시하고, 뒤에는 `docs/PGMS_UI_mock.dc.html`의 목업 anchor ID를 바인딩했습니다(한 항목에 여러 ID가 붙을 수 있음 — 실제 구현 단위 기준으로 묶음). 화면 7의 대안 변형(`7f`/`7g`)은 채택 여부가 아직 정해지지 않아 제외했습니다.

## Phase 0 — 기반

- [ ] MSW mock 핸들러 구조 세팅
- [ ] 로그인(경찰/본사) 화면 + 인증 흐름 (토큰 저장, 인터셉터)
- [ ] 라우터 + `ProtectedRoute` 가드
- [ ] 공용 UI 최소 세트 (버튼/테이블/상태뱃지 등)

## Phase 1 — 핵심 워크플로우 (접수 → 종결 한 바퀴)

- [ ] [본사] 배치요청 목록 + 담당자 배정 — `s6b` `s6c`
- [ ] [본사] 배정 경호건 상세 (기본정보 등록, 근무 스케줄 입력) — `s7a` `s7c` `s7d` `s7e` `s7` `s7b`
